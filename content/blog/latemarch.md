Hello! I'm back! Finally!! Life caught up to me so I had to focus a bit on some other stuff. I'm
back on getting some foundational stuff done, and prepping for the future.

If you're reading this, you're one of the first X users! Congrats! (You'll get an achievement
pretty soon!). I haven't quite done much marketing on the website yet, since I wanted it to be a
bit more sturdy, with a couple more features before sharing it with everyone. It's usable, as you
can clearly see, but there's a lot of kinks I wanted to buff out. Those include:

- Ranger Pass! This is how I plan on monetizing the app. No ads, just a small membership for those

you all updated.
- Feedback form! Wanted an easy way for users to let me know what they like, suggestions, bugs,
etc. This goes directly to my Github board, so not entirely public yet, but I'll address everything
that needs addressing in these 'news' posts.
- Lots of misc. fixes and general improvements. Trying out some Three.js stuff, changed some
sounds and UI stuff in the profile page. Let me know if you like those!

That's all for now! Sorry for taking a while to do another big update. Hopefully the next one comes
sooner hehe. This is a bit of a change in the roadmap, but I'll probably do **podcast support**,
which is something that caught my eye, **signed achievements**, and setting up the payment provider
properly.
